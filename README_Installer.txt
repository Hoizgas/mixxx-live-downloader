Mixxx Live Downloader v1.0.0 — Intel Mac

Installation:
1. Öffne Install.command mit Doppelklick.
2. Bestätige die Installation von Homebrew, falls Homebrew noch fehlt.
3. Bestätige die Installation von yt-dlp und ffmpeg, falls diese Tools fehlen.
4. Der Installer kopiert die App nach /Applications oder ~/Applications und öffnet sie.
5. Beim ersten Start Admin-Nutzer und Passwort einrichten.

Der Installer benötigt macOS 15 oder neuer und Intel (x86_64). Homebrew kann nötige Formel-Abhängigkeiten mitinstallieren.

Die App ist in diesem Release nicht mit einer Developer-ID signiert oder notarisiert. Wenn Gatekeeper sie blockiert, öffne sie im Finder per Rechtsklick > Öffnen und bestätige macOS' Dialog. Der Installer umgeht Gatekeeper nicht.

Im Kontrollpanel lässt sich der Webserver starten und stoppen. Der Server prüft yt-dlp, ffmpeg und ffprobe erneut beim Start und fragt vor einer fehlenden Homebrew-Installation.
